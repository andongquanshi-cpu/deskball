# 轻待办 · Todo Orb

Windows 桌面置顶待办悬浮球，Electron 实现。无账号、无云同步、无外部 API、无开机自启动。

## 运行

已安装依赖后双击 `start.cmd`。开发时在此目录运行 `npm install`、`npm start`。需要 Node.js 22.12 或更高版本与 npm；下载 Electron 首次需要网络。这是源码运行版，不是独立安装包。

## 使用

- 点击圆球展开清单，拖动圆球移动位置。
- 展开后拖动标题栏移动，右上角箭头或 Esc 收起。
- 输入内容后回车添加；勾选完成；× 永久删除该项（第一版无撤销）。
- 全部 / 进行中 / 已完成切换筛选。
- 隐藏后从 Windows 通知区域（可能位于折叠箭头内）点击托盘图标找回。
- 点击退出或托盘菜单退出，结束程序。
- 每次成功修改即保存；不必另点保存。保存失败会显示错误，保留上一次数据。

## 数据与隐私

数据保存在 Electron 的 userData 目录下 `tasks.json`，Windows 通常为 `%APPDATA%\todo-orb\tasks.json`。以托盘菜单“打开数据目录”为准。备份时退出应用并复制该文件。仅保存任务文字与完成状态，不上传网络。文件损坏时拒绝覆盖，请先备份再修复。

## 检查

`npm test` 运行存储测试，`npm run check` 检查脚本语法。

手工验收：启动 → 移动圆球 → 展开 → 添加中文及长任务 → 勾选与筛选 → 收起查看计数 → 退出重开验证保存 → 托盘隐藏与恢复。在多显示器、高 DPI 下检查拖动及窗口边界。

## 结构

- main.cjs：原生窗口、托盘、进程间通信
- preload.cjs：最小权限桥接
- renderer.js / index.html / style.css：清单交互与界面
- store.cjs：数据校验与临时文件替换保存

第一版未提供：提醒、云同步、开机启动、位置记忆、独立 exe 安装包。置顶不保证覆盖系统安全桌面或独占全屏程序。
