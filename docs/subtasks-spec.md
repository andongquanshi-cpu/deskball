# 两层任务：本轮确认范围

## 目标
将大任务拆成可执行的小步骤，同时保留桌面工具的轻量体验。

## 已确认规则
- 支持主任务与子任务两层，不支持三级嵌套。
- 普通任务可以随时添加子任务；添加入口自动展开并聚焦输入框。
- 父项显示完成数 / 总数；有子任务时不能手动勾选父项。
- 全部子任务完成，父项自动完成；取消一个子任务或添加未完成子任务，父项恢复未完成。
- 球上数量与摘要只统计未完成主任务，不重复累计子任务。
- 删除有子任务的主任务，显示包含任务标题、子项数量、不可撤销提示的原生确认框，默认取消。
- 旧格式普通任务兼容读取，不清空、不在读取时重写旧数据。

## 本次实现的边界约定
- 全部 / 进行中 / 已完成按父项状态筛选；展开后显示该父项全部子项，避免隐藏上下文。
- 删除最后一个子任务后，父项恢复为未完成的普通任务，可再次手动勾选。
- 展开状态仅在当前运行会话中保持，重启后默认折叠。
- 每个父项最多 200 个子任务，每项文字最多 300 字符。
- 保存失败保留旧任务和输入草稿，并显示错误。
- 单个子项删除沿用普通任务行为，无撤销；整组删除必须确认。

## 验收清单
- 旧数据打开后，文字与完成状态一致。
- 添加两个子项，进度为 0/2；勾选一个为 1/2；全部勾选后父项完成。
- 在“全部”筛选中取消一个子项或新增子项，父项恢复未完成。
- 一组未完成子项仅增加一个悬浮球计数。
- 折叠、展开不会丢失子项或草稿。
- 删除整组时取消应保留全部任务；确认后删除父项及子项。
- 退出重开后父子关系和完成状态保留。

## 不在本轮范围
无限嵌套、跨组移动、拖拽排序、提醒、云同步和批量勾选。
